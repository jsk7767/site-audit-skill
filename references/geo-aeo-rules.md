# GEO / AEO 판정 근거 — 무엇을 왜 재는가

이 스킬의 G 레인(6범주)이 어디서 왔는지. 출처별 핵심만 우리 말로 옮겼다. 원문 전재 없음.

## 1. 왜 SEO 와 따로 재나 — 9가지 차이 (가이드북 7장)

| | SEO | GEO/AEO |
|---|---|---|
| 정보 소스 | 내 웹페이지 | 플레이스·GBP·블로그·SNS·기사·리뷰를 **종합** |
| 신뢰도 | 도메인 권위(오래·크기) | **현재 평판**(최근 리뷰·갱신 빈도) |
| 형식 | 긴 글 | 구조·명확성(표·리스트·짧은 문장·구조화 데이터) |
| 갱신 | 한 번 잘 만들면 유지 | **지속 갱신** 필수 |
| 경쟁 | 상대적(키워드) | 절대적(실제로 좋아야 상위 3) |
| 키워드 | 핵심 | 의미 매칭 |
| 속도 | 순위 요소 | 거의 무관 |
| 링크 | 백링크 최중요 | **정보 일관성**이 링크보다 중요 |
| 핵심 질문 | 크롤링·색인·구조화되는가 | AI 가 이 비즈니스를 **신뢰**하는가 |

→ 그래서 G 레인은 "크롤러 접근(20) · 기계가독/엔티티(25) · 인용가능성(20) · 신뢰/권위(15) · 최신성(10) · 네이버 NEO(10)" 로 잰다. 성능·백링크는 S 레인에만 있다.

구글 공식 입장(claude-seo seo-geo 요약, 2026-05): "생성형 AI 검색 최적화는 여전히 SEO 다." llms.txt·청킹·AI용 재작성·언급 농사는 효과 미입증. 이 스킬도 llms.txt 를 P2 이하로 둔다.

## 2. CITE (가이드북 8장) — 콘텐츠가 인용되는 4조건

- **C**omprehensive 포괄: 주제의 중요 측면을 초보~전문가 수준까지. → `S-C-thin`, `G-C-*`
- **I**ndependent data 독자 데이터: 내 매장만 아는 숫자(숙성 시간·좌석·주차 대수·월 단골 수). → build-guideline §3
- **T**rust 신뢰: 저자 경력·자격·실적, 법적 공시. → `G-T-person`
- **E**ntity 엔티티: 저자/브랜드 프로필이 구글에서 바로 찾아짐. → `S-S-id, S-S-sameas, G-E-entity`

## 3. E-E-A-T (가이드북 4.4) — AI 가 신뢰하는 4요소

경험(직접 겪음: "우리는 ~했다") · 전문성(자격·경력) · 권위(외부 언급·프로필) · 신뢰(NAP 일관·최신·리뷰). 익명·무날짜·무출처는 약한 신호. → `G-T-*`, `G-F-*`, `G-E-*`

## 4. AI 가 선호하는 구조 (가이드북 9장)

Q&A 형식이 가장 많이 인용된다. 의미 단위 섹션(재료/과정/팁/변형/보관처럼 질문에 바로 대응) · 질문형 소제목("어떻게…?", "왜…?", "언제…?") · 표와 리스트 · 깊이 vs 넓이 중 하나 · 토픽 클러스터. → `G-C-question, G-C-structure, G-C-paragraph`

claude-seo 수치: 인용에 최적 문단 134~167단어, 인용의 ~44% 가 페이지 상단 30% 에서, 3개월 이내 콘텐츠가 ~3배 인용, 6개월+ 방치 시 인용 대상에서 밀림. AI 크롤러는 JS 를 실행하지 않는다 → SSR. 브랜드 언급이 백링크보다 3배 상관.

## 5. 스키마 최소 조건 (가이드북 10장)

LocalBusiness 에 **이름·주소·전화·영업시간** 없으면 AI 가 위치를 못 잡는다. 리치 결과 테스트로 검증. → `S-S-biz-core, S-S-parse`

## 6. 엔티티·NAP (가이드북 11장)

"강남미용실 / 강남美용실 / 강남 미용실" = AI 에겐 세 업체. 엔티티 정의 한 문장(지역+업종+차별점+숫자)을 GBP 소개(150자)·플레이스·블로그 바이오·llms 에 **똑같이**. 지식 그래프 진입 조건: 위키 언급·언론 3건+·GBP 완벽·NAP 통일. → `G-E-name, G-C-lead`

## 7. 자가 진단표 (가이드북 부록 E) — 15항목 × 0~5점

| 범주 | 항목 | 이 스킬 |
|---|---|---|
| NAP | 상호 전 플랫폼 일치 · 주소·전화 100% 동일 · 영업시간 실시간(공휴일) | 자동 3 (사이트 내부·facts) |
| 정보 | 사진 30장+·교체 · 메뉴·서비스 상세 · 소개 150자 엔티티 정의 | 자동 2, 사진 HOLD |
| 리뷰 | 네이버·카카오 50개+ · 평점 4.3+·자연 분포 · 24시간 답글 | HOLD 3 (thejsk) |
| 콘텐츠 | 주 2회 발행 · FAQ 10개+ 구조화 · 업종 전문 콘텐츠 | 자동 1, HOLD 2 |
| 엔티티 | 대표 프로필(경력·자격) · 언론·블로거 노출 연 3회+ · 스키마 또는 GBP 고급 | 자동 2, HOLD 1 |

합계 60+ 상위 10%, 31~60 성장, 0~30 위험. `scores.json.self_diagnosis` 에 자동 8항목 점수와 HOLD 7항목을 둔다. 보고서에는 "8/15 자동" 이라고 쓴다.

## 8. 30일 로드맵 D1 — "AI 가 우리를 아는가" (가이드북 부록 A · 워크북 7장)

1. **시크릿(로그아웃) 창**에서 ChatGPT·Claude·Gemini·Perplexity·네이버 AI 브리핑에 "<상호> 어떤 곳이야?" / "<지역 업종> 추천해줘" → 안 나옴 / 틀리게 나옴(할루시네이션) / 경쟁사에 밀림 기록. 로그인 상태는 개인화라 현황이 아니다.
2. 이길 수 있는 **뾰족한 엣지** 한 문장("서울 저녁 1시간 배송" 식). 쿠팡을 이기려 하지 않는다.
3. **명칭·키 메시지 통일** — 지분을 뭉친다.
4. 타겟을 좁힌다.
5. 봇이 막히지 않은 열린 채널에 **구조화**해 발행. 통이미지·로그인·캡차 뒤는 학습 안 됨.
6. **주·월 사이클** 반복. 컷오프 때문에 오늘 한 것은 다다음 모델에나 반영.
7. **점수화**: 카테고리 질문 리스트 × 모델별 언급 여부·순위 → 언급률 인덱스, 주 단위 추세. "됨/안 됨" 이분법을 넘어 질문별·모델별로 쪼갠다.

→ `G-N-ai-know`(HOLD, 에이전트 수행), `G-N-briefing`(naverai). 결과는 `finding_notes` 와 보고서 "확인한 범위" 에 시점과 함께.

## 9. 네이버 NEO (fire-your-seo-agency neo-naver · 가이드북 부록 C)

- 서치어드바이저 등록·소유확인 → Yeti 허용 → sitemap 제출 → 새 페이지 수집 요청 → 주간 노출/클릭/CTR 확인.
- AI 브리핑 인용 조건: **구조화된 사실**(표) > 산문 · 원출처 링크 · 발행 속도 · **모바일 접힘 위 핵심 정보** · 네이버 앱에서 실제 검색해 출처 칩 기록.
- 두 트랙: 네이버 블로그(신뢰·체류·스마트블록) + 자체 도메인(AI 가 인용할 구조화 사실 페이지). 자연 링크.
- 스마트플레이스 7대(가이드북 C.1): 공식 상호 그대로(키워드 끼워넣기 패널티) · 가장 구체적 카테고리 · 대표 사진 10장 필수·30장+ · 메뉴 사진마다 설명·가격 · 영업시간 실시간·공휴일 · 톡톡/예약 활성 · 스마트콜.
- 영수증 리뷰 1개 = 블로그 리뷰 10개 가치(실방문 증빙).
- FAIL: 자동 서로이웃·댓글, 동일 텍스트 반복, 발행 후 잦은 수정·삭제.
→ `G-N-*`, `G-A-yeti`
